# 各就喵位微信小游戏 · H5 气质 UI 重设计

日期：2026-09-18  
状态：已确认（头脑风暴）  
范围：仅 Canvas UI 视觉与布局；玩法引擎不动

## 目标

把微信小游戏界面从「牛乳贴纸本」（米纸 / 柿红）改为尽量贴近 H5 与 `reference_image/` 的**淡紫治愈**气质：配色、圆角卡片、紫渐变主按钮、棋盘色块、首页与对局骨架、浮层文案。不追求与 H5 DOM 像素级 1:1。

## 已确认决策

| 项 | 选择 |
|----|------|
| 视觉方向 | A · 尽量贴 H5 配色与气质 |
| 布局结构 | A · 按参考图重排首页 / 对局 / 浮层骨架 |
| 首页大猫 | A · Canvas 手绘靠拢（无位图资源） |
| 实现路径 | 1 · 主题换皮 + 在现有 `theme` / `paint` / `app` 上重绘 |

材料：`D:\Github\Purrdoku\h5`（色板与文案）、`reference_image/`（截图）。

## 实现落点

| 文件 | 职责 |
|------|------|
| `src/ui/theme.ts` | 色板、区域色、难度名、圆角工具 |
| `src/ui/paint.ts` | 纸面背景、猫/爪/标记、首页大猫与装饰 |
| `src/ui/app.ts` | 各 scene / modal 布局、hit 区、文案 |
| `game.js` | `npm run build` 产物 |

**明确不改：** `src/engine/*`、`src/game/*`（除若设置 UI 过滤项外）、存档 key、手势时序、静态题池。

## 非目标

- 像素级复刻 H5 DOM / SVG  
- 引入猫插画位图或字体文件  
- 实现音效 / BGM  
- 重构 UI 为多文件组件层（可后续再拆）  
- 改玩法或难度节奏  

## 验收标准

1. 首页、对局、设置、怎么玩、提示在观感上能对应 `reference_image/`（紫、圆角、卡片层级）。  
2. 闯关、每日、撤销、提示应用、设置开关、清档仍可用。  
3. `npm test` 与 `npm run build` 通过；主包体积无异常暴涨。  

## 风险与对策

- Canvas 插画与 H5 不完全一致 → 接受「靠拢」；优先圆框、气泡、漂浮色块的可读性。  
- 对局信息密度高导致小屏挤 → 优先保证棋盘可点面积，规则条可缩字。  
- 旧存档主题无关 → 无需迁移。
